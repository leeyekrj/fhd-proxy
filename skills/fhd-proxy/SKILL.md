# FHD Proxy

CLI 정본: https://github.com/leeyekrj/fhd-proxy. 설치된 `fhd-proxy --help`로 현재 옵션을 확인한다. Python 3.9 이상과 FFmpeg가 필요하며 기본 인코더는 macOS VideoToolbox다.

- 입력은 파일 또는 폴더. 폴더는 바로 아래 영상만 처리한다. 우선 `fhd-proxy <입력...> --dry-run`으로 출력 이름과 충돌을 확인한다.
- 기본 출력은 원본 옆 `Proxy/<같은 이름>.mov`. 외장 디스크가 불안정하거나 한곳에 모을 때는 `--output <폴더>`를 쓴다. 서로 다른 입력이 같은 출력 이름을 만들면 폴더를 나눈다.
- 기본 `--quality 75 --jobs 2`. 다른 작업 중이면 `--jobs 1`. 목표 용량 압축 기능이 아니므로 결과 크기나 속도를 보장하지 않는다. 입력 총량과 출력 디스크 여유 공간을 확인하고 긴 변환은 백그라운드로 실행한다.
- 결과는 1920×1080 범위 안에서 종횡비를 유지하며 확대하지 않는 HEVC Main10 MOV. 오디오는 복사한다. 알려진 색 태그·풀/비디오 레인지·타임코드와 영상 길이를 검증한다. LUT 적용이나 색 공간 변환은 하지 않는다. 소스에 색 태그가 없으면 원래 색 공간을 추측하지 않는다.
- 원본과 기존 출력은 덮어쓰지 않는다. 실패·취소하면 이번 임시 출력만 정리한다. 오류가 있으면 종료 코드가 0이 아니므로 파일 일부만 성공한 배치를 전부 완료했다고 보고하지 않는다. 기존 출력은 별도로 원본과 검증하거나 다른 출력 폴더로 실행한다.
- DaVinci Resolve: 원본 선택 → **Link Proxy Media** → 출력 폴더. 편집 중 Prefer Proxies, 최종 렌더는 **Use proxy media**를 끄고 원본으로 확인한다. 동일한 이름의 여러 카메라 클립은 폴더별로 연결한다.

예: `fhd-proxy "/Volumes/Camera/Card A" --output "$HOME/Movies/Proxies/Card A" --jobs 1`

완료 보고에는 파일별 성공/실패, 출력 위치, 용량을 포함한다. 프록시 색·타임코드 태그 검증이 편집기의 실제 시각적 색 일치를 증명하는 것은 아니므로 중요한 원본은 편집기에서 대조한다.
